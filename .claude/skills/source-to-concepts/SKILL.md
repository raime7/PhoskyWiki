# 从原典整理概念词条

以可追溯的原文摘录建立概念词条。模型负责概念判断和简短说明，程序从固定来源组装引文。数量是编辑结果，完整性和忠实性是验收标准。

## 确定本轮边界

从会话与已有计划承接已确定的书目、译本、章节、背景范围、交付阶段和发布目标，只询问仍缺失且影响执行的信息。首次试验以一个可完整评阅的章节为单位。

明确本轮是材料整理、只建概念页、添加作者视角，还是发布已审定内容。“只建概念页”时仍可整理本地摘录材料，但不能自行添加作者视角。采用以下默认编辑规则，用户明确选择优先：

- 收集章内出现的哲学概念；有实质论述者整理完整摘录，仅提及者可建概念页并标记待补。
- 背景限于本轮约定范围且确有理解需要的段落，单列章外背景；其他章节只登记待补出处。
- 正文、说明、附释及关联译注分层保留；摘录包含定义、论证、反驳、例子和必要过渡。
- AI 导语简短、有依据、注明资料范围，置于具名诠释者视角的引文之外，明确为整理说明，不冒充原作者论述。概念页只承载导航信息，不另建站方指导视角。

交付一份简短范围记录，列清本轮边界及尚未解决的决定；不要把上次试验的章节、目标地址或发布授权当成本次默认值。

## 固定来源并建立段落索引

执行前阅读 [来源、双链与校验细则](references/extraction.md)。保存原文件指纹和实际章节原始内容，给每段稳定 ID，保留层次、定位、强调和译注关联。只清理可证明属于电子书排版的噪声，逐项记录；校勘意见另列。

检查章节起止、正文与附释续段、注释链接和强调范围。索引必须足以从冻结来源重新生成每条引文，不能只留下模型摘抄的文本。

## 建立概念与原段的对应

先通读全章列候选概念，再逐段分配，最后按词形反查遗漏。词形匹配只提示候选；无关键词的论证或过渡也可能必须收录。

每个概念记录规范名、别名、同义判定依据、实质论述或仅提及状态、原段 ID、关联概念和章外待补。按概念而非字面词形立条：有充分证据才合并别名；含义可能不同则检索原典或可靠学术来源，保留出处；仍不能判断则请用户裁决，继续处理已确定部分。外部检索用于术语判定，不混入指定原典的摘录。

逐段记录收录到哪些概念，或排除原因。出现哲学概念但缺乏展开时记录“仅提及”；不能为凑词条数编造作者论述。完成条件是范围内每段有可复查的去向，而不是所有关键词都有页面。

## 组装正文与行文双链

通过段落 ID 从固定来源确定性组装，按原文顺序保留所需完整段落。同段涉及多个概念时允许各条重复完整收录，使用统一出处标识。保留原词、标点、段落、强调及关联译注；解释和校勘与引文分开。

在行文中的概念出现处加双链，不能仅在文末列相关词条。别名使用 `[[规范名|原词]]`，例如 `变易是[[存在|有]]与[[无]]的统一` 的可见文字保持不变。“有”指向“存在”须有本轮已经确认的同义依据。

每段每概念首个语义合适的出现加链，跳过当前词条自链，优先识别长概念。按已审定段落关联限制链接；单字词和普通修饰语必须核实语义。记录人工排除项，允许其跨原有强调边界生效。具体误链和渲染陷阱见细则。

## 校验、评阅和交付

独立从冻结来源复核段落、层次、译注及内容指纹，再核对全部生成引文和覆盖记录。通过目标站点的真实 Markdown 管线检查可见文字、强调范围和双链目标；原文忠实性不能用 Markdown 源码相等代替。

交付概念决策清单、逐段覆盖记录、成稿、校勘与待补清单、校验结果及全部页面或草稿的评阅索引。用户逐篇评阅概念粒度、论证完整性、上下文和导语。无标记改字、误归属、漏关键论述或断章取义均需修正并重验。

明确区分自动校验通过与人工语义评阅完成。当前技能源自《小逻辑》“A．质”试点的已验证技术流程；历史试点的逐篇人工评阅仍未完成，不能声称已经证明语义穷尽。扩展时沿用本轮反馈修正规则。

用户要求入站或同步时，继续阅读 [PhoskyWiki 发布与同步](references/phoskywiki.md)，完成已授权阶段；仅整理材料或创建技能的请求不触发数据库写入。
