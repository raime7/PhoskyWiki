# 来源、双链与校验细则

## 最小可追溯材料

在本轮独立产物目录中保存以下信息；文件可合并，证据不能省略：

| 材料 | 必须能回答的问题 |
| --- | --- |
| 来源清单 | 哪本书、哪个译本、哪个文件及 SHA-256、哪些章节或成员文件、何处起止、哪些为背景？ |
| 段落索引 | 原段 ID、节号、层次、定位锚点、原始文本、规范化文本、原有强调、译注关联及哈希是什么？ |
| 注释索引 | 正文注号实际链接哪条注释，注释原文与署名层次是什么？ |
| 规范化日志 | 哪项排版噪声被清理，清理前后是什么，理由是什么？ |
| 概念决策 | 规范名、别名证据、实质或提及、原段引用、歧义、待补及链接排除项是什么？ |
| 覆盖清单 | 每段在哪些概念中完整摘录或仅作提及，排除有什么具体理由？ |
| 成稿与校验 | 来源能否重建成稿，实际渲染是否保留可见文字与强调，哪些人工判断待评阅？ |

原始书籍、全文摘录和数据库备份保存在适当的本地产物目录；项目中的 `artifacts/content-pilots/` 为历史用例。共享技能只包含方法，不夹带用户原书、凭据或数据库备份。

## 提取边界

针对实际文件检查目录、章节标题及标记后编写或适配提取器。EPUB 中一个 XHTML 可能包含多章；层次标签只出现在首段，后续段可能仍属同一附释。不能用空行或固定标签猜测完整边界。

依据内部链接配对译注，不依据显示数字猜测。历史试点中正文 `[33]` 实际指向章末 `[1]`，应分别保留两处显示编号并记录关联。保持黑格尔正文与译者注释的归属可辨。

空白清理须适配当前文件，不能一律合并所有空白。原文中的疑似错字、异常希腊字形及标点原样保留，校勘意见单列。`与源文件一致` 不等于 `源文件不存在排印错误`。

## 双链与渲染

先保存纯来源，再生成带链接的展示层；不得回写来源。链接操作保留原有强调范围和可见字符。

- 长名称优先，避免将“自为存在”拆成“存在”，或把“别物自身”误判为“物自身”。
- 有、无、一、多、质、量等单字只有在概念语境中加链；强调、引号、明确对举可以提供证据，仍需语义判断。“没有”“一般”中的字不是自动链接目标。
- “规定在”可能是“规定＋在”；“绝对不同”“绝对贫乏”等可能只是程度修饰。排除清单记录原段 ID、原短语和理由，而非添加全书通用黑名单。
- 排除项可能横跨加粗标记，应在可见文字坐标中判断并映射到展示层。
- 中文紧接 `**强调**` 时，目标解析器可能把星号显示为文字；原始 HTML 强调标签也可能被过滤。使用实际渲染器验证。历史脚本使用行内不可见注释辅助分隔，但段首先放 HTML 注释可能吞掉整段 Markdown，应针对具体管线处理。

## 验证判据

1. 从冻结原始章节独立重解析，核对完整段落和注释清单，检测来源或中间数据被改动。
2. 全部引文能由决策清单引用的原段重建；范围内每段均有具体去向；背景和待补不会伪装成核心摘录。
3. 全量渲染后，可见原文与规范化来源逐字一致，强调范围一致，译注完整；仅移除已记录的展示性出处标记等附加结构进行比较，不能广泛删除标点或空白来掩盖差异。
4. 双链规范目标存在或明确列入本轮待建集合，别名显示原词；人工检查语义误链。
5. 若新增提取或链接代码，用小型合成材料验证续段归属、注号错位、强调与链接共存，并确认篡改引文会使校验失败。验证不能只比较两个共享同一错误的生成结果。
