# 中文 humanizer：去掉 AI 腔

润色子代理按这份规则改写解读与一句话核心（[润色子代理提示词](polish-prompt.md)）。分类参照英文维基的 “Signs of AI writing”，按中文的习惯改过。目标是一位细心的编者写的、清楚的现代中文：每句话都有信息，句式随内容变化，术语前后一致。

`validate` 用 `scripts/book-pipeline/style-patterns.ts` 机检其中能用正则认准的一部分，命中时给出 `style.ai-pattern` 提示，不阻断。下面各类都要逐句检查，包括机检认不出的那些。

## 1. 套话与空洞强调

| 类型 | 例子 | 改法 |
| --- | --- | --- |
| 提示语 | 值得注意的是、需要指出的是、值得一提的是 | 删掉，直接说要点 |
| 空洞的确定 | 不难看出、显而易见、毋庸置疑、毫无疑问、不言而喻、无疑 | 删掉；成立与否交给摘录 |
| 公式化收束 | 总而言之、综上所述、由此可见、总的来说 | 删掉整句总结，或只留其中的新信息 |
| 含糊限定 | 可以说、在某种意义上、在一定程度上 | 删掉；确有限定就说清在什么意义上 |
| 拔高与评价 | 深刻地揭示、振聋发聩、精辟地指出 | 删掉修饰，只说诠释者说了什么：这类词本身就是评价，违背“不评价” |
| 意义宣称 | 至关重要、不可或缺、具有重要意义、发挥着关键作用、占据着重要地位、意味深长、有效地防止、精髓所在、提供了全新的视角 | 说出具体起什么作用；说不出就删 |

改完一句后检查：删去套话以后，这句话还剩信息吗？没剩就整句删掉。

> 改前：值得注意的是，范例思深刻地揭示了开端问题的重要意义。
> 改后：范例思认为，开端的困难出自开端的概念本身。

## 2. 反射式对举

“不是……而是……”“不仅……更是……”“与其说……不如说……”。先立一个没人主张的说法再推倒，是最常见的 AI 腔。

- 只在指出一种**确有的**常见误读时用“不是……而是……”，每个论点最多一次。
- 其余直接正面陈述：“A 不是 X，而是 Y” → “A 是 Y”。
- “不仅……更是……”改成两句平铺，或只留后一项。

## 3. 三连排比

三个抽象名词并列（“历史性、辩证性与总体性”）、三个结构相同的分句、三个形容词叠用。列几项由原文决定：原文说了两点就写两点，平行的分句改成有先后、有因果的普通句子。

## 4. 公式化的总-分结构

段首一句总述、中间“首先……其次……最后……”、段尾再总述一遍。论点标题已经陈述了主张，解读不必开头复述、结尾再收束。段内按文风档案「论证次序」推进，用文风档案「推理与转折」里的连接词标出推理关系。

## 5. 句长与节奏

句子长短一律、每句都塞四字格、每段都是三四句，读起来像模板。

- 长句里套了三层以上的“的”或分句链，拆开。
- 一连串碎句，合并成有主次的长句。
- 四字格每句至多一个，换成具体的说法。

## 6. 标点

- 破折号：每个论点至多一处；能用逗号、句号或“也就是”就不用。
- 冒号：用于引出列举或引语。“X：Y”式的解释改成完整的句子。
- 分号串起的长链拆成句号。
- 粗体不用于解读里的强调；列表只用于确实平行、各自完整的几项，其余写成段落。

## 7. 翻译腔

摘录是译文，保持原样；解读借用译名，但用中文句法。

| 翻译腔 | 改法 |
| --- | --- |
| 被理解为、被认为是、被视为 | 主动句：“黑格尔把 A 理解为 B” |
| 对……进行分析／考察 | 直接用动词：“分析……” |
| 作为……的 A，它…… | 拆开：“A 是……。它……” |
| 一个／一种（“一种辩证的运动”） | 不需要计数时删去 |
| 当……的时候，…… | “……时，……”或直接用连接词 |
| 使得、从而使 | 写出谁做了什么 |
| 代词过多（“它的”“他的”接连出现） | 换回名词或删去 |

## 8. 含糊归属与对读者喊话

- “有学者认为”“一般认为”“人们常说”：这是引入他人观点，属 `foreign-view`。常见误读要写成具体的读法（“把开端读成任意的起点”），再用原文说明诠释者为何不这样看。
- “让我们”“我们可以看到”“不妨”：主语改回诠释者（“范例思指出……”）。

## 9. 同义轮换

为了不重复而轮换同义词（存在／存有／有）。同一术语始终用文风档案里的译名，与双链的显示文字一致；重复术语不是毛病。

## 10. 仿写原文

借用诠释者的**术语**和**论证次序**，不借他的句子。

- 文风档案「仿写风险」列出的句式、文言词（毋宁、乃、之、亦）、反问与感叹，一律改成平实的现代中文。
- 引文之外不照录原文：与冻结来源连续 20 字相同即 `exposition.verbatim-source` 错误。确需原话就留给摘录；解读里只用短引语（术语、几个字的说法），加引号。
- 读者应当一眼分得清：这句是编者在讲，那段是诠释者原话。

## 保持不变

- 意思：限定词（“可能”“在……意义上”）反映原文的分寸时保留；推测不写成断言，断言不弱化成推测。
- 术语、原文注（“定在（Dasein）”）、双链的目标与显示文字。
- 补出的推理仍标明是在解释原文。
- 篇幅：润色只删不增，不补充新内容。
