# 中文 humanizer：视角润色的专用规则

润色子代理（[润色子代理提示词](polish-prompt.md)）先读通用技能 `.claude/skills/humanizer-zh/SKILL.md`：编辑约束的优先级、31 个检查点（下称 zh§n）和交付前核对都照它做。本文件只写视角这种文体特有的规则（下称 P§n），与 humanizer-zh 冲突时以本文件为准。目标是一位细心的编者写的、清楚的现代中文：每句话都有信息，句式随内容变化，术语前后一致。

视角不是普通散文：解读只陈述诠释者的立场，原文只经摘录进入视角，双链与术语原文注是数据。所以 humanizer-zh 中“保留作者声音”在这里指保留解读已有的分寸和论证，不指模仿诠释者；“肯定表达优先”指每段先说诠释者的主张、再给依据。诠释者本人的否定性论证（如“量的辩证法不是单纯返回到质，而是进展到尺度”）是内容，照原分寸保留。

`validate` 用 `scripts/book-pipeline/style-patterns.ts` 机检其中能用正则认准的一部分，命中时给出 `style.ai-pattern` 提示，不阻断。下面各类都要逐句检查，包括机检认不出的那些。

## P1. 评价与空洞的确定

zh§12、zh§13、zh§15 之外，视角另有两条：

- 拔高词（深刻地揭示、振聋发聩、精辟地指出）本身就是评价，违背“不评价”：删掉修饰，只说诠释者说了什么。
- 空洞的确定（不难看出、显而易见、毋庸置疑、毫无疑问、不言而喻、无疑）：删掉，成立与否交给摘录。

> 改前：值得注意的是，范例思深刻地揭示了开端问题的重要意义。
> 改后：范例思认为，开端的困难出自开端的概念本身。

## P2. 反射式对举

比 zh§1 更严：“不是……而是……”只用于指出一种**确有的**常见误读，或转述诠释者本人的否定性论证，每个论点最多一次。其余直接正面陈述；“不仅……更是……”改成两句平铺，或只留后一项。

## P3. 总-分结构

论点标题已经陈述了主张，解读不必开头复述、结尾再收束（参 zh§24、zh§31）。段内按文风档案「论证次序」推进，用「推理与转折」里的连接词标出推理关系；列几项由原文决定（参 zh§6）。

## P4. 句长、四字格与标点

- 长句里套了三层以上的“的”或分句链，拆开（zh§26）；一连串碎句，合并成有主次的句子（zh§2）。
- 四字格不要每句都有；空泛的换成具体说法（zh§29）。
- 破折号每个论点至多一处（zh§8）。“X：Y”式的解释改成完整的句子；分号串起的长链拆成句号。
- 解读里不用粗体；列表只用于确实平行、各自完整的几项，其余写成段落。

## P5. 翻译腔

摘录是译文，保持原样；解读借用译名，但用中文句法（参 zh§11、zh§27、zh§28）。

| 翻译腔 | 改法 |
| --- | --- |
| 被理解为、被认为是、被视为 | 主动句：“黑格尔把 A 理解为 B” |
| 对……进行分析／考察 | 直接用动词：“分析……” |
| 作为……的 A，它…… | 拆开：“A 是……。它……” |
| 一个／一种（“一种辩证的运动”） | 不需要计数时删去 |
| 当……的时候，…… | “……时，……”或直接用连接词 |
| 使得、从而使 | 写出谁做了什么 |
| 代词过多（“它的”“他的”接连出现） | 换回名词或删去 |

## P6. 含糊归属与对读者喊话

- “有学者认为”“一般认为”“人们常说”引入他人观点，属审稿的 `foreign-view`，不是 zh§17 那种可以保留的归因。常见误读要写成具体的读法（“把开端读成任意的起点”），再用原文说明诠释者为何不这样看。
- “让我们”“我们可以看到”“不妨”：主语改回诠释者（“范例思指出……”）。

## P7. 同义轮换

为了不重复而轮换同义词（存在／存有／有）。同一术语始终用文风档案里的译名，与双链的显示文字一致；重复术语不是毛病。

## P8. 仿写原文

借用诠释者的**术语**和**论证次序**，不借他的句子。

- 文风档案「仿写风险」列出的句式、文言词（毋宁、乃、之、亦）、反问与感叹，一律改成平实的现代中文。
- 引文之外不照录原文：与冻结来源连续 20 字相同即 `exposition.verbatim-source` 错误。确需原话就留给摘录；解读里只用短引语（术语、几个字的说法），加引号。
- 读者应当一眼分得清：这句是编者在讲，那段是诠释者原话。

## 保持不变

zh 的「编辑约束与优先级」第 1 条之外：

- 限定词（“可能”“在……意义上”）反映原文的分寸时保留；补出的推理仍标明是在解释原文。
- 术语、原文注（“定在（Dasein）”）、双链的目标与显示文字。
- 篇幅：润色只删不增，不补充新内容。
