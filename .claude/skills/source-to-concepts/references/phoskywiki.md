# PhoskyWiki 发布与同步

仅在用户要求入站或发布时加载。先读当前 [内容生产说明](../../../../docs/content-production.md) 和 [领域上下文](../../../../CONTEXT.md)，以当前代码与接口为准。操作远端时另读 [生产环境说明](../../../../docs/production.md)。

## 确定数据语义与范围

Term 是只承载导航信息的概念枢纽；Perspective 是具名诠释者对概念的视角，各视角平等并列。创建词条时填写标题、简介、别名和关键文本等信息；`new_term` 及词条批量导入的 `content` 应省略或为空字符串，非空正文会被拒绝。原典摘录通过 `new_perspective` 另行提交到对应作者的视角，AI 导语明确标为整理说明并置于引文之外。

执行前核实配置所指向的实际数据库、站点与库存，读出规范名、别名、诠释者、当前修订及相关分类。按规范身份映射，发现别名冲突或同名歧义先解决。跨库重新映射 ID，不能复制本地主键。

列出本次将新增、复用、更新和暂不处理的对象，以及所需依赖。明确“本轮新增”“本轮依赖的旧页”“全部本地旧内容”三者范围。远端不一定已有本地旧页；只有用户授权的集合进入同步。

学派关联诠释者，分类关联概念页。同步这些结构时核对成员、父子关系及缺失的依赖对象；已授权的依赖补齐继续执行，超出范围的内容单独列出。

## 写入与中断恢复

保存目标备份和变更前快照，运行材料与凭据保持在受保护的本地目录。普通内容优先使用正常管理员内容接口，使修订、双链和搜索更新走站点管线。先建或匹配全部概念枢纽与诠释者，再写视角。

每次提交前持久记录操作意图、稳定身份、目标 ID、基础修订和预期正文哈希；成功后登记结果修订。响应丢失时先查询实际结果再决定重试。与预期相同的内容复用，避免重复页面与修订。

更新已有正文前核对当前修订与哈希，保护用户后续编辑。替换本批次生成区块时，保留第一次实际写入前的内容；应从台账对应的真实 `beforeRevisionId` 恢复，而不是从更早的库存快照推测。存在并发变更或缺失历史时停止该项，报告具体冲突并继续独立项。

分类或学派接口不足时，先检查当前项目支持方式；如确需维护脚本，限定授权对象、备份和事务范围。历史一次性 SQL 不是默认发布途径。整库替换、演示 seed、账号或讨论迁移不由内容同步请求自动授权。

## 写后核验

核对所有目标对象、当前正文与修订、别名、诠释者归属和分类关联，确认非目标现有内容保持。按站点需要执行 [双链协调](../../../../docs/reconcile-links.md)，检查遗留红链是否原本存在；记录原因，不能为消除红链随意创造内容。

通过实际页面验证可见引文、强调及双链跳转，并核实搜索、图谱或分类等受影响入口。交付新增与复用计数、范围差异、校验结果、冲突和完整评阅索引。发布成功不代替用户的语义评阅。

需要复用历史实现时阅读 [本地试点入站脚本](../../../../scripts/hegel-pilot-site.mjs)，其目标与产物路径固定于历史本地试点，不能当作远端或通用导入器直接运行。[全量同步记录](../../../../docs/reports/local-content-sync.md) 说明了本轮集合与全库集合的差异；记录中的库存和目标状态须重新实测。历史报告中的编委会视角属于已移除的旧模型，不作为当前生产对象或同步依赖；复用历史材料时按当前内容模型筛选。
