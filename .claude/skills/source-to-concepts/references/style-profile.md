# 文风档案

确认候选之后、写第一份论点映射之前读。写 `style/profile.md`：这位诠释者怎么用词、怎么推进论证。写解读和润色时都照它**借用**术语与论证次序（ADR-0009）。一个工作目录只有一份；增量运行时先读旧档案，新书带来新术语或新的论证方式就追加，不另起一份。

## 写法

通读全部 `reading.md`（增量时重点读新书），按 `scripts/book-pipeline/types.ts` 的 `STYLE_PROFILE_SECTIONS` 顺序，每节一个 `## 标题`。每条都附段落 ID，让写解读的人能回到原文核对。档案记的是可借用的**素材**：词、步骤、连接词。所以每条都写成要点，不抄原文句子，也不写长段落。

### 术语与译名

关键术语逐条写：译本的译名、原文（取自候选的 `originalTerms` 或译者注）、首次出现的段落 ID。同一原词在本译本里有不同译法时，写明本书用哪一个、在哪里用另一个；与站上词条名不同的，注明对应的词条名。解读里用译本的译名，首次出现时注原文，例如“定在（Dasein）”。

### 论证次序

诠释者展开一个概念时的惯常步骤，例如“先给出直接的规定 → 指出它自身包含的矛盾 → 由矛盾过渡到下一个规定”，或“先驳常识看法 → 再立自己的定义”。写解读时，论点的排列和每段解读内部的推进照这个次序走。

### 推理与转折

原文里标示推理关系的连接词和转折方式（“因此”“这就是说”“但是”“毋宁说”……），各举一处段落 ID。只列写现代中文时也自然的那几个；生僻或文言色彩重的列入下一节。

### 仿写风险

一借就会像原文的东西：诠释者标志性的句式和腔调，译本特有的文言词、长定语、倒装，反问和感叹（“难道……吗？绝不！”）。写解读时这些都避开，句子用清楚的现代中文：读者应当一眼看出哪段是编者的说明、哪段是引文。

## 完成条件

四节都在，标题与 `STYLE_PROFILE_SECTIONS` 逐字相同（缺节即 `validate` 的 `style.profile-missing`）。术语一节覆盖了全部已确认概念及其解读里会用到的相关术语，每条都有段落 ID。没有一条是整句抄录原文。
