# R03: 删除与恢复后的视角入口一致

> 已发布：https://github.com/raime7/PhoskyWiki/issues/21。优先级：P2。对应 Spec 用户故事：19–22。

## Parent

https://github.com/raime7/PhoskyWiki/issues/18

## What to build

删除视角、词条或诠释者后，读者在所有公开入口看到一致的不可用状态；恢复后有效关系自动恢复。

遵循父 Spec 与 ADR-0001～0004；每项功能连同相关接口、页面及外部行为测试一起交付。测试以 HTTP 和渲染 DOM 为主，使用隔离的真实 PostgreSQL；纯函数测试仅作补充。

## Acceptance criteria

- [ ] 统一视角、所属词条和诠释者均未软删除的可见性判定，覆盖内容读取、双链目标、来源反链和热度、图谱、推荐与搜索同步。
- [ ] 已解析但不可见的显式视角链接不显示正常蓝链，不回退其他目标，也不计入尚未创建词条的写作缺口。
- [ ] 父页面删除不改写子视角独立删除标记，不丢失已解析目标 id；恢复仅使满足全部条件的视角重新可见。
- [ ] 分别删除视角、词条、诠释者并恢复，以 HTTP 和浏览器验证链接、反链、图谱及发现结果；保留单独删除的子视角不可见。
- [ ] 对搜索派生索引按既有同步方式处理关联视角；验证公开搜索不会因父页面删除漏过滤。

## Blocked by

None (can start immediately).
