# R06: 词条信息编辑、审核与改名闭环

> 已发布：https://github.com/raime7/PhoskyWiki/issues/24。优先级：P2。对应 Spec 用户故事：4–11。

## Parent

https://github.com/raime7/PhoskyWiki/issues/18

## What to build

编者从词条页编辑标题、简介和别名，经审核后公开；管理员可以直编，改名后原有引用继续可达。

遵循父 Spec 与 ADR-0001～0004；每项功能连同相关接口、页面及外部行为测试一起交付。测试以 HTTP 和渲染 DOM 为主，使用隔离的真实 PostgreSQL；纯函数测试仅作补充。

## Acceptance criteria

- [ ] 词条页区分编辑词条信息与编辑通俗视角，复用表单及本地草稿；词条正文仍位于视角。
- [ ] 扩展既有提交入口，支持词条全量元数据提案和独立基准修订；审核 UI 逐字段展示差异。
- [ ] 普通编者遵循 quorum 快照、两票/冷启动与终态规则；管理员直编立即生效，均产生可追踪全量快照。
- [ ] 旧数据缺少可恢复结构化历史时，从当前真实元数据建立明确起始快照，保留旧历史，不伪造过去字段；迁移兼容既有提交。
- [ ] 过期 base 被明确驳回；标题唯一性在生效事务内校验，冲突无部分写入。
- [ ] 改名保持页面 id、旧 URL 及已解析普通/显式双链可达；别名只展示，不参与名称解析。
- [ ] 生效管线更新公开元数据、历史记录与搜索等派生输出；通过 HTTP 和浏览器验证草稿、提交前后可见性、审核及旧链接。
- [ ] 任意修订比较与回滚界面由 R07 完成；本工单交付可独立演示的编辑到公开流程及其快照基础。

## Blocked by

None (can start immediately).
