# R07: 词条信息历史比较与安全回滚

> 已发布：https://github.com/raime7/PhoskyWiki/issues/25。优先级：P2。对应 Spec 用户故事：12。

## Parent

https://github.com/raime7/PhoskyWiki/issues/18

## What to build

管理员查看和比较词条元数据历史，并通过生成新修订恢复到可恢复的历史快照。

遵循父 Spec 与 ADR-0001～0004；每项功能连同相关接口、页面及外部行为测试一起交付。测试以 HTTP 和渲染 DOM 为主，使用隔离的真实 PostgreSQL；纯函数测试仅作补充。

## Acceptance criteria

- [ ] 修订历史与任意两版比较展示标题、简介、别名的真实变化，能辨认新建、普通受理与管理员直编。
- [ ] 回滚产生新修订并记录来源，不篡改历史；页面元数据、URL 展示和搜索等派生输出同步更新。
- [ ] 回滚遵循标题唯一性和事务一致性，冲突时明确失败且当前内容不变。
- [ ] 对 R06 建立起始快照之前无法恢复的旧历史，明确说明限制；历史仍可查看，不猜测旧字段。
- [ ] HTTP 与浏览器覆盖编辑两次、任意两版比较、回滚、改名冲突及旧历史兼容；回滚后既有 id 链接仍可达。
