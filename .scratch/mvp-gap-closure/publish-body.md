## What to build

维护者依据 Spec #18 的完整验收矩阵判断本批缺口是否关闭，读者与编者的跨模块流程有可复现的验证证据。

遵循父 Spec 与 ADR-0001～0004；每项功能连同相关接口、页面及外部行为测试一起交付。测试以 HTTP 和渲染 DOM 为主，使用隔离的真实 PostgreSQL；纯函数测试仅作补充。

## Acceptance criteria

- [ ] 在固定实现提交上逐项映射 Spec 的八项评审发现、用户故事和验收矩阵，记录已验证行为及材料。
- [ ] 组合验证改名→双链校对→旧链接、删除父页面→受理驳回→恢复→重提、词条元数据编辑→历史回滚，以及游客推荐过滤不可见视角。
- [ ] 四个评审临时探针对应的缺陷均有正式外部行为回归；图谱有安全文本的真实浏览器验证。
- [ ] 运行类型检查、lint、构建、Vitest 与相关 Playwright；服务契约测试清楚列出通过、失败及环境跳过，不以跳过宣称通过。
- [ ] 运行并记录隔离环境中的存量校对演练和重复执行结果；给出目标环境校对操作说明，不擅自对生产执行迁移或校对。
- [ ] 各功能工单自身已带测试；本工单只补组合流程、运行整体验收并汇集证据，不用收口代替未交付功能。
- [ ] 如发现范围内失败，修复并重新验证相关项后才报告交付完成；保留明确未解决项，不自动关闭或修改父 Spec。
