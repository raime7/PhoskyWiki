# 0001 - PostgreSQL 作为唯一内容存储

站内全部内容（词条、视角、修订、双链、审核队列、用户）存于 PostgreSQL，而非 Markdown 文件 + git。决定性理由：三轴导航（词条 × 诠释者 × 学派）、兴趣推荐和两票审核流本质上是关系查询，文件方案撑不住。代价是修订对比与回滚必须自建（git 方案原本白送），与 Obsidian 等文件笔记生态的互导需要专门的导入导出工具。

## Considered Options

- Markdown + git（被否）：修订历史免费、可直连 Obsidian 生产管线，但多轴导航/推荐/审核需要另建索引层，最终等于维护两套存储。
