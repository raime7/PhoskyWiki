# 0005 — 同名词条归并与可选关键文本

- 状态：已接受，2026-09-08
- 依据：[MVP 收束规格](../specs/0003-mvp-consolidation-and-optional-key-texts.md)

同名概念跨领域共用一个词条，按诠释者分流；同一诠释者对同一词条只有一篇视角，按章节说明不同领域或含义。此规则替代 ADR-0003 第 5、6 条中的括号分词条和独立消歧义页规则。保留统一页面壳、标题唯一与 id 寻址。数据库旧枚举值只供存量迁移识别，不再提供对应路由和创建入口。

关键文本为词条与诠释者信息框的可选有序作品列表。缺少作品不阻止发布，由管理员判断内容质量。修改沿用现有审核与修订：省略字段保留，空列表清空；旧修订未记录该字段时回滚保留当前列表并提示。

一次性整理直接归并公开内容和讨论、改向内部链接、清除隐藏内容与废弃来源及其独占依赖。保留页的正常历史和待审内容继续保留；不复制来源审核票、不自动发布来源提案，不增加来源档案、撤销合并或永久重定向。此处是 ADR-0004 历史保留规则针对本次废弃对象的例外；以后的正常删除仍为可恢复软删除。
