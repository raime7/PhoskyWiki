# Agent 解读（T14）

游客可在词条页或视角页侧栏使用 Agent 解读。展开「模型配置」，填写 OpenAI 兼容端点的 baseURL（包含服务商要求的路径，如 `/v1`）、API key 和模型名，再保存。程序向 baseURL 后追加 `/chat/completions`；端点需要允许浏览器跨域请求（CORS），并支持 SSE 流式 Chat Completions。

配置保存在当前站点的浏览器 localStorage，刷新后保留；「清除配置」会删除三个字段。配置不随账号同步。问题、回答与阅读路径仅在当前页面内存中保留，离开页面后清空。HTTPS 端点和本机 HTTP 端点可用；禁止把本站同源地址配置为模型端点。

填写问题并点击「发送问题」即可逐段查看回答。「生成阅读路径」把问题框作为可选学习目标，按学习顺序展示词条链接及学习理由。生成时可停止，已收到的文字会保留；网络、认证、格式和中途断流错误会显示在面板中，可再次发送重试。

`GET /api/agent/context?termId=<id>` 是公开的只读内容 API，只接收词条 id。上下文包含当前词条简介及已发布视角，以及双链入链/出链一跳邻居的相同内容；精确指向视角的双链按所属词条扩展。排除红链、二跳内容、旧修订及软删除页面（含所属词条或诠释者被删除的视角）。正文经站点 Markdown 管线渲染后提取可见文本。

问答由浏览器直接请求使用者配置的端点。请求不带站点 cookie、不发送 Referer、不跟随重定向；站点 API 不接收密钥或问题。回答中的 `[1]` 等编号由应用根据本次上下文回填成词条/视角地址，未知编号保留为文本。模型输出不会作为 HTML 执行。解读可能有误，可点击引用核对原文；如果模型不遵守阅读路径格式，会保留原始回答并提示重试。

验证命令：

```sh
pnpm exec vitest run tests/integration/agent.test.ts
pnpm exec playwright test tests/e2e/agent.spec.ts
```

浏览器测试使用本机模拟端点验证真实 CORS 请求和分片 SSE，其余响应通过浏览器网络边界模拟，不需要真实 API key 或模型费用。
