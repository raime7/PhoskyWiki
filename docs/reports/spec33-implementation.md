## 实施结果

- 同名词条使用一个枢纽；同一诠释者的重复视角按章节归并。去除独立消歧义创建、目录与路由，更新种子和领域决策。
- 词条与诠释者提供可选、有序关键文本。覆盖编辑、草稿、受理、旧提案、显式导入更新、历史 diff 和回滚；省略保留现值，空列表清空，旧快照缺字段保留当前值。
- 编辑正文、基准修订及解析关系在同一读取快照内取得。过期草稿继续保留，展示最新版对照，人工确认前不能提交；再次刷新仍保留该限制。
- 讨论锚点遵循视角及其父页面的完整可见性；搜索命中回复后可定位到实际回复。
- 一次性归并命令先盘点目标与数量，要求非空备份，事务内迁移公开内容与关系并清理废弃来源，成功后重建搜索。保留正常页面历史、提案和共享图片，不发布来源待审内容。
- 集成测试及其 CLI 子进程显式禁用开发搜索；浏览器使用独立数据库与 `MEILI_INDEX_UID` 指定的专用索引。
