# T16：首页与演示入口

关联：GitHub #17。

首页以搜索为主要入口，配本周概念、新视角、学派巡礼。词条索引位于 `/terms`，诠释者索引位于 `/interpreters`，学派入口沿用 `/schools`；三轴入口同时出现在全站站头与首页。

本周概念目前按词条创建顺序选取前六项，作为首期编辑陈列；新视角按发布时间倒序展示六项，学派巡礼取前三个在线学派。页面与相关诠释者软删除后不进入新视角和推荐。首页没有自动轮播或入场动画，只在悬停时改变颜色。

登录后的「为你发现」读取账号兴趣，复用词条相关推荐的计分规则：诠释者（包含关注学派展开的成员）视角数 + 主题分类命中数。只显示匹配项，最多六项。未设兴趣时引导设置，无匹配时提示调整；游客继续使用公共编辑陈列。

## 演示种子

本地或 CI 的空数据库先运行 `pnpm db:migrate`，再运行 `pnpm db:seed`；需要搜索演示时运行 `pnpm search:reindex`。`db:seed` 会清空内容表，只适用于开发或演示数据库。

复用 `src/db/seed.ts` 的手写核心内容和 `src/db/seed-extended.ts` 的扩容内容：111 个词条、305 个视角、26 位诠释者、7 个学派，覆盖哲学、政治经济学与历史。扩容视角正文已注明是导航和图谱的示意内容，不作为经过校订的完整诠释。

T16 增加一条由扩容视角指向「价值（哲学）」的确定双链，连接手写核心与扩容网络。此前随机候选中的核心链接可能没有进入实际正文。现有 1,755 条已解析双链让全部 111 个词条处于同一个连通网络。

## 验证入口

- `tests/e2e/home.spec.ts`：首页搜索、编辑陈列、三轴跳转、账号兴趣推荐。
- `tests/integration/home.test.ts`：种子数量、三领域分类、正文双链与全网连通性，主题兴趣推荐。
- `tests/e2e/mobile.spec.ts`：375 × 812 触屏浏览器内搜索提交、词条展开阅读、图谱定位跳转、游客讨论阅读与登录发言，检查页面无横向溢出。

移动端站头随页面滚动，三轴导航可换行。选择图谱搜索结果后关闭下拉框，避免遮挡「已定位」跳转入口。
